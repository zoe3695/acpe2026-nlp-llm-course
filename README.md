# Machine Learning in Real-World Drug Studies

**ACPE 2026 Educational Session, Track C** · Friday 30 October 2026

[![Course website](https://img.shields.io/badge/course-website-blue)](https://zoe3695.github.io/acpe2026-nlp-llm-course/)

This track introduces the foundational concepts, principles, and applications of natural language processing (NLP) and large language models (LLMs) in real-world pharmacoepidemiologic studies. Participants will gain practical exposure to basic coding workflows and machine learning–driven disease phenotyping strategies, while learning to critically evaluate epidemiologic biases in NLP/LLM-enhanced analyses.

Part of the [Asian Conference on Pharmacoepidemiology (ACPE) 2026 educational
sessions](https://www.asianpharmacoepi.org/educational-sessions/).
